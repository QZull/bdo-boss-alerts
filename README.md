# Респ боссов

Портативный таймер мировых боссов **Black Desert (RU)** для Windows. Расписание, напоминания со звуком, всплывающие уведомления поверх игры и иконка в трее.

Это неофициальное приложение. К Pearl Abyss, Kakao Games и официальному клиенту BDO не относится.

## Скачать

Готовый файл лежит не в исходниках, а на вкладке **[Releases](https://github.com/QZull/bdo-boss-alerts/releases/latest)** — как у обычных Windows-программ на GitHub.

1. Откройте **[последний релиз](https://github.com/QZull/bdo-boss-alerts/releases/latest)**
2. В блоке **Assets** скачайте `Resp-bossov-….exe`
3. Положите файл в любую папку и запустите

Установка не нужна. Рядом с exe при первом запуске появится папка `data` (настройки, свои звуки и картинки). Её не удаляйте и не отправляйте друзьям — у каждого свои настройки.

> Windows может показать предупреждение SmartScreen: приложение не подписано сертификатом. Нажмите **Подробнее** → **Выполнить в любом случае**.

## Возможности

- Недельная сетка мировых боссов RU (московское расписание, UTC+3)
- Сдвиг отображения под ваш часовой пояс
- Напоминания за выбранное время (в том числе «сейчас»)
- Свои звуки и громкость, отдельные звуки на напоминание
- Всплывающее окно поверх игры (лучше работает в оконном безрамочном режиме, не в эксклюзивном полноэкранном)
- Включение и выключение боссов, свои боссы и слоты
- Автозапуск вместе с Windows
- Масштаб интерфейса 80–150%

## Запуск из исходников

Нужны [Node.js](https://nodejs.org/) 22+ и Windows.

```powershell
npm install
npm run dev
```

Сборка портативного exe в `dist\Resp-bossov.exe`:

```powershell
npm run build
```

Перед сборкой полностью закройте приложение (в трее: **Выход**), иначе файл будет занят.

## Как появляется релиз

Новая версия на вкладке Releases создаётся автоматически, когда в репозиторий отправляется **git-тег**.

```powershell
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions соберёт exe и прикрепит его в **Assets**. Номер в имени файла берётся из тега (`v1.0.0` → `Resp-bossov-1.0.0.exe`). Версию в `package.json` лучше держать той же.
