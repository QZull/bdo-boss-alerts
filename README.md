## Как скачать

1. Откройте страницу **[последней версии](https://github.com/QZull/bdo-boss-alerts/releases/latest)**
2. Внизу, в блоке **Assets**, скачайте файл **`Resp-bossov-….exe`**
3. Положите его в любую папку и запустите — устанавливать ничего не нужно

Не скачивайте **Source code** — это исходники, а не программа.

> Windows может показать предупреждение SmartScreen. Нажмите **Подробнее** → **Выполнить в любом случае**. Это обычная реакция на программу без цифровой подписи, а не признак вируса.

## Как пользоваться

После запуска откроется расписание на неделю. Напоминания и звук настраиваются в **Настройках**. Закрытие окна прячет программу в трей (рядом с часами), полностью выйти можно из меню иконки.

Рядом с файлом появится папка `data` — там хранятся ваши настройки. Её не нужно отправлять друзьям: им достаточно одного exe.

Чтобы уведомление было поверх игры, запускайте BDO в **оконном безрамочном** режиме, не в эксклюзивном полном экране.

## Что умеет

- Расписание мировых боссов RU
- Напоминания за выбранное время и в момент респа
- Свои звуки, громкость и картинки боссов
- Можно выключить ненужных боссов или добавить своих
- Автозапуск вместе с Windows
- Масштаб окна и свой часовой пояс для отображения
